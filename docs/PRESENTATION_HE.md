# הסבר קצר להצגה

בניתי אתר שמקבל תמונת פנים ומסווג אותה ל״עם מסכה״ או ״ללא מסכה״. השתמשתי במאגר Kaggle שהמרצה קישר, ובחרתי רק את שתי המחלקות האלה. אחרי ניקוי כפילויות חילקתי את הנתונים לאימון, ולידציה ומבחן, כדי לבדוק את המודל על תמונות שלא שימשו ללמידה או לבחירת האפוק.

הרשת היא CNN קטן מאפס, לפי השיעור: שתי שכבות Conv2D עם ReLU ו־MaxPooling, אחריהן Flatten, שכבה צפופה של 128 נוירונים ופלט Sigmoid יחיד. ה־Sigmoid מייצג את ההסתברות ל״ללא מסכה״. באימון השתמשתי ב־Adam וב־binary crossentropy, ושמרתי את המודל בעל שגיאת הוולידציה הנמוכה ביותר.

כל תמונה מומרת ל־RGB, משתנה ל־64×64, ומנורמלת בחלוקה ב־255. אותו עיבוד בדיוק מתבצע בשרת. שמרתי את המשקולות בקובץ `.keras`, יחד עם מיפוי התוויות והגדרות העיבוד, טענתי מחדש ובדקתי שהתחזיות נשמרות.

FastAPI טוען את המודל פעם אחת בהפעלת השרת. באתר אפשר לצלם בטלפון או לבחור קובץ, לראות תצוגה מקדימה, לשמור את התמונה למכשיר ולבצע סיווג בנפרד. התמונה אינה נשמרת בשרת.

אימנתי ב־Google Colab עם GPU במשך 20 אפוקים. המודל שנבחר מאפוק 16 הגיע לדיוק 94.17% על 1,321 תמונות מבחן. התוצאות המלאות נמצאות ב־README וב־reports/evaluation.json. המודל מוגבל לשתי מחלקות, אינו מאתר פנים ואינו מבין בהכרח תמונה ללא אדם. הדיוק במאגר אינו הבטחה לדיוק בכל צילום אמיתי.

שאלות נפוצות: Validation משמש לבחירת המודל; Test רק להערכה הסופית. Pooling מקטין את מפות התכונות. Dropout והגדלת שונות נועדו להפחית שינון. הסתברות גבוהה אינה הוכחה שהתחזית נכונה.

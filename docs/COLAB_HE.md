# Colab — ריצה קיימת ושחזור

האימון בחשבון Colab כבר הסתיים: גרסה `20261017T175219Z`, 20 אפוקים, T4 GPU, דיוק מבחן 94.17%. אין צורך לאמן שוב כדי להפעיל את האתר.

## בדיקת תמונה נוספת אחרי ביטול ההעלאה

1. פתחו את המחברת. אם הסביבה עדיין מחוברת והמשתנים קיימים, עברו ישר לתא התחזית בסעיף 8.
2. לחצו על ▶ בצד **התא**, לא על כפתור Choose Files הישן שבתוך הפלט. כפתור הבחירה הישן נעשה לא פעיל לאחר ביטול; הרצת התא יוצרת כפתור חדש.
3. בחרו תמונת פנים אחת בפורמט JPEG/PNG/WebP. הביטול מטופל בהודעה בעברית, ללא אימון.
4. אחרי הצגת התמונה, התווית וההסתברויות, הריצו רק את תא הייצוא בסעיף 9 כדי להוריד דוח תחזית מעודכן.

## אם הסביבה התאפסה

1. אל תלחצו Run all. חברו סביבת ריצה והריצו את תא הסביבה בסעיף 1 (התקנת תלויות וחיבור Drive בלבד).
2. הריצו את תא הגדרות העיבוד בסעיף 3 ואת תא פונקציות העזר הראשון בסעיף 4. אין צורך להריץ הכנת נתונים, בניית מודל או אימון.
3. הריצו את תא השחזור בתחילת סעיף 8. הוא בודק את `MyDrive/Project03_VISION/models` ו־`reports`. אם התוצרים בריצת משנה, הגדירו `RUN` לנתיב הריצה המתאים לפני התא.
4. הריצו את תא התחזית, בחרו תמונה, ואז את תא הייצוא. המודל נטען מקובץ קיים.
5. שמרו ב־File → Save, ואז File → Download → Download .ipynb כדי לשמור מחברת עם הפלטים. אם יש שגיאת שמירה, הורידו עותק מקומי לפני רענון.

## הקבצים הדרושים לחיבור לאתר

1. הורידו `vision03-model-artifacts.zip` מהתא האחרון. עותק נשמר גם בתיקיית הריצה ב־Drive.
2. לפני החלפה, גבו את תיקיות `models`, `reports`, `notebooks` ואת README.
3. חלצו והעתיקו יחד את `models/mask_cnn.keras` ואת `models/metadata.json` לתיקיית `models` באתר. ההגדרות כוללות מיפוי תוויות, עיבוד תמונה ו־SHA-256 מחייב.
4. העתיקו את `reports` ואת המחברת עם הפלטים לתיקיות המקבילות. עדכנו את התוצאות ב־README לפי הריצה בפועל.
5. הפעילו מחדש את FastAPI. בדקו `/api/health`, העלאה → תצוגה מקדימה → שמירת תמונה → סיווג, והריצו `python -m pytest -q`.

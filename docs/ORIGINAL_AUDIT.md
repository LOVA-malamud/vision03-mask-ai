# Original application and preservation

The existing cat/dog application was inspected before adaptation. It used React/TypeScript/Vite and FastAPI with a genuine trained CNN. The original cat/dog project was kept separately and was not overwritten. A separate face-mask project reused its working upload, preview, theme, and API components.

The submission contains only the face-mask application. The original cat/dog model, unrelated workspace, private machine paths and training datasets are not included. Backups of earlier face-mask deliverables remain locally outside this repository.
